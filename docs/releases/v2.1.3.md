# Ontocode CLI 2.1.3

Ontocode CLI 2.1.3 ships an unsigned Linux x86_64 binary.

## Fixed

- Loading repository policy before tool execution no longer counts as a failed tool call for the repeated-failure redirect. Parallel tool calls can each receive that policy-loading response; those responses no longer consume the redirect intended for repeated execution failures.
- Actual repeated tool failures retain the existing redirect behavior.

## Compatibility

- Existing configuration and state databases remain compatible.
- Content pack v11 remains the current separately released agents-and-skills pack.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.3
```

The binary reports `Ontocode CLI 2.1.3`. Release assets include the binary, installers, project-plan template, and SHA-256 checksums.
