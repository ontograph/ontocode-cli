# Ontocode CLI 2.1.2

Ontocode CLI 2.1.2 ships an unsigned Linux x86_64 binary.

## Fixed

- A manager-loop transition killed while it held the tracker lock no longer blocks later transitions on that tracker. The lock is now an OS file lock on `<plan>.md.integrate.lock`, which the operating system releases when the holder exits; a second live holder still gets "integration already in progress". The lock file stays on disk and can be ignored by version control.
- Resuming a session whose rollout contains lines this build cannot read now logs a warning that names each skipped line's type and the number of lines dropped. Previously those lines were skipped silently.

## Changed

- The embedded `ontocode-memory-bank` system skill is shorter and points at the project-plan authoring template instead of carrying its own copy. The template shipped in the binary is now the single source.

## Verified

- If a role-result integration fails between claiming the receipt and writing the tracker, or between writing the tracker and consuming the receipt, one retried call with the same arguments completes it. New tests prove both cases; no write-order change was needed.

## Compatibility

- No state database changes. Databases written by earlier versions open as before.
- Content pack v11 is the current agents-and-skills pack; it is released separately.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.2
```

The binary reports `Ontocode CLI 2.1.2`. Release assets include the binary, installers, project-plan template, and SHA-256 checksums.
