# Ontocode CLI 2.1.4

Ontocode CLI 2.1.4 ships an unsigned Linux x86_64 binary.

## Fixed

- Requests for `qwen-qwen-4` on the configured `cliproxyapi` provider send developer messages with the system role, addressing the Alibaba API error that rejects the developer role.
- Message contents, metadata, and ordering remain intact. Existing request-history validation still runs before adaptation, and other models and providers retain their existing behavior.

## Compatibility

- Existing configuration and state databases remain compatible.
- The compatibility rule applies to the exact model ID `qwen-qwen-4` and a case-insensitive `cliproxyapi` provider ID.
- Content pack v11 remains the current separately released agents-and-skills pack.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.4
```

The binary reports `Ontocode CLI 2.1.4`. Release assets include the binary, installers, project-plan template, and SHA-256 checksums.
