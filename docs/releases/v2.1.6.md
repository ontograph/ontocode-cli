# Ontocode CLI 2.1.6

Ontocode CLI 2.1.6 ships an unsigned Linux x86_64 binary.

## Changes

- Keeps provider model discovery working when catalog entries advertise unsupported input modalities such as audio. Supported text and image capabilities remain available; malformed modality values are still rejected.
- Adds catalog decoding and HTTP endpoint regression coverage.
- Simplifies the shipped project-plan authoring template.

## Distribution

Content pack v11 remains separately versioned. Release assets include the binary, installers, project-plan template, and SHA-256 checksums.

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.6
```

The binary reports `Ontocode CLI 2.1.6`.
