# Ontocode CLI 0.4.2.2

This internal fix release restores authorized manager-loop retry overrides after
a task has reached its normal attempt cap. Its Cargo package version is
`0.4.2+2`; the CLI and other machine-readable version surfaces report
`0.4.2+2`, while the GitHub tag, installer input, and release assets use
`0.4.2.2`.

## Included Assets

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- `install-ontocode-linux-x64.sh`
- `install-ontocode-linux-x64-v0.4.2.2.sh`
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- `release-notes-v0.4.2.2.md`

## Fixes

- honors an active, authorized task-local model override even when the task's
  ordinary attempt count is exhausted
- preserves the attempt-cap stop for tasks without an override
- preserves the consumed-override stop so a single-use authorization cannot be
  reused
- defaults release installation and documentation to the public distribution
  repository `ontograph/ontocode-cli`

## Scope

- includes source commit `87c1a6e2ab` and its focused manager-loop tests
- builds on the published `rust-v0.4.2.1` release source and evidence commits
- excludes unrelated changes from the main checkout
- preserves all existing release tags
