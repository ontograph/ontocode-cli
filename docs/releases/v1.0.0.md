# Ontocode CLI 1.0.0

Linux x86_64 release. The CLI reports `1.0.0`; the release tag is `rust-v1.0.0`.

- Preserves complete session records when recovering large interrupted writes.
- Strengthens provider-history ordering and privacy regression coverage.
- Adds bounded repeated-poll protection and tool-argument rejection evidence.
- Improves MCP recovery, plan validation and execution-session handling.

This release changes the major version. Existing configuration and session data
remain in place. Keep a backup before upgrading. macOS and Windows binaries are
not included. Content Pack v9 remains independently versioned and unchanged.

Install:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 1.0.0
```

Verify downloaded assets using the release `SHA256SUMS` file.
