# Ontocode CLI 2.1.1

Ontocode CLI 2.1.1 ships an unsigned Linux x86_64 binary.

## Fixed

- Resumed threads now restore their pending manager-loop waits, so a wait
  registered before a resume is observed again instead of being dropped.
- A suspended manager-loop wait is re-registered when its observation
  fingerprint changes. Previously the re-registration was ignored.
- `manager_loop_advance` `reopen` can replace an active task that is
  `IMPLEMENTED_PENDING_VALIDATION` when the manager runs with
  `dispatch_mode: none`. The replaced task keeps its status and evidence.

## Changed

- The default base instructions have a revised approval rule, a "finish the
  work you owe" rule, a note on the cost of delegating to sub-agents, a rule
  that each bug fix keeps its reproducing check as a permanent regression test,
  and shorter formatting guidance. The Claude Fable persona files were updated
  to match.
- Sub-agent reliability and search-tool tests were added; no behavior change is
  attributed to them.

## Known gaps

- The prompt change above has not passed the scaffold-evaluation gate. Its
  improvement record has no frozen cases, no scored runs and no independent
  reviewer, and the decision field still reads `revise`. It ships on the
  maintainer's explicit instruction to release, not on evaluation evidence.
  Treat it as unevaluated.
- Memdoor reliability measurement is incomplete. A clean paired baseline and
  candidate comparison has not been run, so this release makes no claim about
  token or latency savings.

## Compatibility

- No state database changes. Databases written by earlier versions open as
  before.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.1
```

The binary reports `Ontocode CLI 2.1.1`. Release assets include the binary,
installers, project-plan template, and SHA-256 checksums.
