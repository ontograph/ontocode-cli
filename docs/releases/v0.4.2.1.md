# Ontocode CLI 0.4.2.1

This internal development release candidate restores progress through
manager-loop model routing failures. Its Cargo package version is `0.4.2+1`;
the CLI and other machine-readable version surfaces report `0.4.2+1`, while
the GitHub tag, installer input, and release assets use `0.4.2.1`.

## Included Assets

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- `install-ontocode-linux-x64.sh`
- `install-ontocode-linux-x64-v0.4.2.1.sh`
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- `release-notes-v0.4.2.1.md`

## Fixes

- treats a model-specific unsupported reasoning-effort rejection as a retryable
  manager-loop route failure
- preserves the requested reasoning effort while advancing to the next approved
  model candidate
- keeps service-tier, provider, prompt, capability, permission, and policy
  failures terminal

## Scope

- includes the bounded `MRF-1.0` implementation and its focused tests
- excludes `MRH-1.0` terminal-receipt metadata hydration and unrelated
  dirty-worktree changes
- preserves the published `rust-v0.4.2` tag and release

## Release Gate

Publish only from a clean curated commit after focused manager-loop and CLI
tests pass, the release binary reports `Ontocode CLI 0.4.2+1`, bundled skills
are verified, the installer smoke passes, and `SHA256SUMS` covers every uploaded
asset. Tag the exact commit as `rust-v0.4.2.1`; do not move existing tags.
