# Ontocode CLI 2.1.7

Ontocode CLI 2.1.7 ships an unsigned Linux x86_64 binary.

## Changes

- `/model` opens from the current catalog without waiting for provider discovery. A background refresh supplies the next opening without replacing the current view.
- CLIProxyAPI model discovery keeps listed aliases, including Qwen aliases, when their API-support flag is absent or false. Hidden models and other providers retain their existing filters. Listing an alias does not verify inference support.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.7
```

Release assets include the binary, installers, the project-plan template, and SHA-256 checksums. Content pack v11 is unchanged. The binary reports version `2.1.7`.
