# Ontocode CLI 0.4.2.5

This internal development fix release packages the reviewed private source
snapshot prepared on August 23, 2026. Its Cargo package version is `0.4.2+5`;
the CLI and other machine-readable version surfaces report `0.4.2+5`, while
the GitHub tag, installer input, and release assets use `0.4.2.5`.

## Included Assets

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- `install-ontocode-linux-x64.sh`
- `install-ontocode-linux-x64-v0.4.2.5.sh`

- `release-notes-v0.4.2.5.md`
- curated agents and skills content pack plus manifest
- `install-content-pack.sh`

## Fixes

- prevents assistant-prefill requests from reaching provider request paths
- aligns bounded sub-agent spawn selection with the current configuration APIs
- preserves active-task selection for concurrent worktree validation flows
- makes the default CLI installer select the newest `rust-v*` release even
  when a newer independently versioned content-pack release exists
- moves detached compiler receipts to the managed Ontocode artifact root while
  preserving explicit legacy paths
- rejects unsafe managed job names and symlinked artifact roots, records
  ownership metadata, and never deletes existing compiler receipts implicitly
- synchronizes the manager-loop prompt, project-plan template, build guidance,
  and Excel migration plan with the current release contracts
