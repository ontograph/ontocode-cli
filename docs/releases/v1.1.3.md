# Ontocode CLI 1.1.3

This Linux x86_64 release improves structured tool history, provider error handling,
and task verification.

- Preserve custom tool calls and results when using compatible Responses endpoints,
  including a successful retry after a repository-policy refusal.
- Preserve native tool history for Anthropic, Gemini and Copilot requests.
- Stop retrying terminal provider responses such as output limits and content filters.
- Include bounded, redacted completion results in subagent notifications.
- Require matching repository and source evidence for graph-gated task acceptance.
- Add bounded waiting when reading a detached validation result.

Compatible Responses endpoints must support structured custom-tool history.

The release includes an unsigned Linux binary, checksum-verifying installers,
and the project-plan template. Optional agents and skills remain independently
versioned in the existing content pack.
