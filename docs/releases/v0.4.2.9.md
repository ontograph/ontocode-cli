# Ontocode CLI 0.4.2.9

This internal fix release packages the complete authorized source snapshot
prepared on September 6, 2026. Its Cargo package and machine-readable CLI
version are `0.4.2+9`; the GitHub tag, installer input, and release assets use
the human release identity `0.4.2.9`.

## Included assets

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- public-repository installers for the CLI and content pack
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- curated agents-and-skills content pack v8 and manifest

## Fix-release scope

- Serializes role-result receipt writes with SQLite `BEGIN IMMEDIATE`, making
  concurrent identical replays idempotent across processes.
- Supersedes corrected results for an unconsumed dispatch binding while keeping
  the predecessor as non-live history; consumed integration evidence remains
  immutable.
- Carries the complete authorized tracked and untracked development changes,
  including manager-loop tests, role policy updates, migration support, and
  documentation.
- Publishes release documentation, installers, binary, and content pack only
  through `ontograph/ontocode-cli`.

## Release gate

The release is publishable only after focused source checks, formatting, a clean
native release build reporting `Ontocode CLI 0.4.2+9`, content-pack verification,
checksum validation, public-reference leak scans, and anonymous installer smoke
checks pass.
