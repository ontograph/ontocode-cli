# Ontocode CLI 1.1.9

Ontocode CLI 1.1.9 ships an unsigned Linux x86_64 binary.

## Added

- Excel tools gain bounded `read_sheet_range`, `search_workbook`, and
  `query_sheet_rows` operations.
- Release builds embed their source commit and build identity, and the release
  receipt is bound to the build manifest.
- Project-plan tasks can declare an `action_budget` for builds and test runs.
  The budget is stored durably, is never refunded after a crash, and is
  reserved before a covered compiler-lane launch.
- Manager-loop plans support a guarded `reopen` action, a no-progress budget for
  repeated continuation prompts, and recovery of open sub-agents when a thread is
  resumed, including through the app server.

## Changed

- Excel: oversized but valid worksheets are reported as resource-limited
  instead of corrupt; formula coverage and family counts are checked for
  consistency; legacy VBA success fields are deprecated; duplicate warnings are
  removed.
- The memories and Ontograph tools adopt a small set of tool-schema
  improvements.
- Resumed sessions no longer read state storage on the turn hot path to decide
  whether a sub-agent is retired, and resume work no longer holds the global
  thread lock during file and database I/O.
- Base instructions are consolidated: conflicting guidance is removed, and the
  minimal-change rule states that it targets speculative features, not the
  requested scope, refactoring of touched code, or tests.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 1.1.9
```

The binary reports `ontocode 1.1.9`. Release assets include the binary,
installers, project-plan template, and SHA-256 checksums. Agents and skills
continue to ship separately as a content pack.
