# Ontocode CLI 2.1.5

Ontocode CLI 2.1.5 ships an unsigned Linux x86_64 binary.

## Changes

- Refreshes empty inherited model catalogs through the configured provider before validating sub-agent model selections. Cached catalogs keep their existing fast path, and unknown model IDs remain rejected.
- Includes provider model-catalog, MCP configuration, and tool-discovery updates.

## Distribution

Content pack v11 remains separately versioned. Release assets include the binary, installers, project-plan template, and SHA-256 checksums.

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.5
```

The binary reports `Ontocode CLI 2.1.5`.
