# Ontocode CLI 0.4.2.8

This internal development fix release packages the complete authorized source
snapshot prepared on September 6, 2026. Its Cargo package and machine-readable
CLI version are `0.4.2+8`; the GitHub tag, installer input, and release assets
use the human release identity `0.4.2.8`.

## Included assets

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- public-repository installers for the CLI and content pack
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- curated agents-and-skills content pack and manifest

## Fix-release scope

- Carries all authorized tracked and untracked development changes from the
  source checkout, including session, configuration, Ontograph, protocol,
  model-manager, TUI, diagnostics, documentation, and tooling updates.
- Publishes release documentation and installers only through
  `ontograph/ontocode-cli`.
- Builds Content Pack v7 from the reviewed allowlist using home-managed
  `$ONTOCODE_HOME/skills` and `$ONTOCODE_HOME/agents` definitions.
- Uses deterministic archive metadata, checksums, public-reference leak scans,
  and temporary-install validation.

## Release gate

The release is publishable only after focused source checks, formatting, a clean
native release build reporting `Ontocode CLI 0.4.2+8`, content-pack
verification, checksum validation, public-reference leak scans, and anonymous
installer smoke checks pass.
