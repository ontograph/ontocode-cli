# Ontocode CLI 1.1.8

Ontocode CLI 1.1.8 ships an unsigned Linux x86_64 binary.

## Changed

- Sessions with no explicit permission selection now start with the
  `:danger-full-access` profile and the `never` approval policy, so commands run
  without sandboxing or approval prompts. Project trust no longer selects the
  implicit profile. Explicit configuration and command-line selections keep their
  precedence. Select a restricted profile, for example
  `default_permissions = ":read-only"`, to keep containment.
- Organization-managed requirements still constrain the result. When a managed
  network requirement is present, the implicit default stays on the contained
  workspace profile so the managed network proxy is not bypassed. A requirement
  that forbids full access falls back to a compliant approval policy.
- Truncated exec output is archived with completeness metadata, local exec
  output backpressures a slow consumer instead of dropping chunks, and tool-plan
  schemas have byte ceilings.
- MCP resource and template listing share one `list_mcp_resources` tool with a
  `kind` argument. Resource tools appear only when a started server advertises
  resources, and Excel specialist tools are deferred in searchable turns.
- Claude requests carry prompt caching, and the Claude message-thread path
  falls back to one full request when a thread is lost. No paid latency
  measurement was made.
- Responses WebSocket requests are counted as incremental or full, and a
  Responses stream failure that reports a previous response as not found is
  retried instead of ending the turn.
- Project-plan validation accepts local-improvement code paths in plans that use
  `dispatch_mode: none`.


Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 1.1.8
```

The binary reports `ontocode 1.1.8`. Release assets include the binary,
installers, project-plan template, and SHA-256 checksums. Agents and skills
continue to ship separately as a content pack.
