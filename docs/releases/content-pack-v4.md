# Content Pack v4 — `content-pack-v4`

Standalone curated agents and skills update published independently of the CLI
binary.

- 25 agent definitions
- 27 skills
- deterministic archive and manifest with SHA-256 digests
- installer refuses to overwrite existing destinations
- omitted `--release` selects the newest published content pack

The browsable `pack/` directory on `main` is generated from the same release
archive. See the [release assets](https://github.com/ontograph/ontocode-cli/releases/tag/content-pack-v4)
for the archive, manifest, installer, and checksums.
