# Ontocode CLI 1.1.7

Ontocode CLI 1.1.7 ships an unsigned Linux x86_64 binary.

- Ontograph impact results include the source line of a call site when available.
- Linux sandbox setup avoids creating metadata mount targets in shared temporary roots and reclaims orphaned targets.
- Updates bytes to 1.12.1, lru to 0.16.3, constant_time_eq to 0.5.0, and tracing-test to 0.2.6.
- Improves test isolation for temporary directories, Git fixtures, and asynchronous hooks.
- Redirects the model after repeated identical tool failures, including failures inside code-mode nested calls and PostToolUse feedback, and keeps the redirect past the deferred-context limit.
- Records sub-agent observations and workspace checkpoints during manager-loop integration.
- Adds an opt-in decisions API smoke pilot command.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 1.1.7
```

The binary reports `ontocode 1.1.7`. Release assets include the binary,
installers, project-plan template, and SHA-256 checksums. Agents and skills
continue to ship separately as a content pack.
