# Ontocode CLI 2.1.8

Ontocode CLI 2.1.8 ships an unsigned Linux x86_64 binary.

## Changes

- Directs main sessions to coordinate delegated work and prefer an eligible DeepSeek model with high reasoning for sub-agents.
- Requires model requests to use the configured runtime transport and tells agents to proceed when only optional or duplicate paperwork remains.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.8
```

Release assets include the binary, installers, the project-plan template, and SHA-256 checksums. Content pack v11 is unchanged. The binary reports version `2.1.8`.
