# Ontocode CLI 0.4.2.10

Internal fix release for the Ontocode CLI, published under `rust-v0.4.2.10`.
The Cargo and machine-readable CLI version is `0.4.2+10`.

## Included

- Linux x86_64 unsigned `ontocode` binary
- CLI installers and `SHA256SUMS`
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- release documentation and the independently versioned Content Pack v9

## Fix scope

- rejects superseded role-result integration receipts before validation or
  tracking mutation
- preserves the manager-loop tracking file when a superseded receipt is
  rejected
- adds regression coverage for the rejection and preservation behavior

The release is an internal development prerelease. See the
[GitHub release](https://github.com/ontograph/ontocode-cli/releases/tag/rust-v0.4.2.10)
for downloadable assets and checksums.
