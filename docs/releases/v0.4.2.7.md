This internal development fix release packages the reviewed source snapshot
prepared on September 3, 2026. Its Cargo package and machine-readable CLI
version are `0.4.2+7`; the GitHub tag, installer input, and release assets use
the human release identity `0.4.2.7`.

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- public-repository installers for the CLI and content pack
