# Ontocode CLI 2.1.11

Ontocode CLI 2.1.11 ships an unsigned Linux x86_64 binary.

## Changes

- Synthesizes `reasoning_text` from summary items so DeepSeek reasoning replay works on OpenAI-compatible gateways that omit reasoning deltas.
- Applies the CLIProxyAPI settings to the full DeepSeek model family, matching gateway-side family defaults instead of exact model IDs.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.11
```

Release assets include the binary, installers, the project-plan template, and SHA-256 checksums. Content pack v11 is unchanged. The binary reports version `2.1.11`.
