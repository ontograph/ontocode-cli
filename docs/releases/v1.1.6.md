# Ontocode CLI 1.1.6

## Fixed

- Prompt history stays valid when a hosted tool-search output arrives before
  its call or repeats while calls are pending. Such an output is kept when a
  later output completes the call, matching the request validator, instead of
  being dropped or failing the turn.
- The compatibility adapter scopes completed and local-shell call ids to the
  provider turn. A call id reused in a later turn no longer turns that later
  output into an assistant message.
- The Fable coordinator recognizes coding requests such as "add a method" or
  "create a function" again.
- A batch of only receipt-only turn contexts no longer writes an empty thread
  metadata update.

## Changed

- The Fable coordinator may run the read-only OntoIndex facade tools,
  including the freshness check and discovery actions. The retired
  `gn_inspect` and `gn_search` names are no longer admitted.
- The unreachable image-generation extension has been removed.

## Validation

- `ontocode-tui` library and integration tests: 2857 passed.
- cli, exec, mcp-server and thread-store: 503 passed; core `multi_agents`:
  365 passed.

## Distribution

This release provides an unsigned Linux x86_64 binary, installers, the project
plan template and SHA256 checksums. The optional content pack is unchanged.
