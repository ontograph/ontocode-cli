# Ontocode CLI 2.1.10

Ontocode CLI 2.1.10 ships an unsigned Linux x86_64 binary.

## Changes

- Fixes CDR physical spawns so they receive the coder contract used for runtime validation.
- Reports an unavailable manager role through the typed no-dispatch path.
- Applies the CLIProxyAPI system-role compatibility rule to the full DeepSeek model family.
- Retries empty proxy keepalive responses that incorrectly report an output-token limit.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 2.1.10
```

Release assets include the binary, installers, the project-plan template, and SHA-256 checksums. Content pack v11 is unchanged. The binary reports version `2.1.10`.
