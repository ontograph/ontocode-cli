# Ontocode CLI 0.4.2.12

Internal fix release for the Ontocode CLI, published under
`rust-v0.4.2.12`. The Cargo and machine-readable CLI version is `0.4.2+12`.

## Included

- Linux x86_64 unsigned `ontocode` binary
- CLI installer and `SHA256SUMS`
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- release documentation

## Fix scope

- includes the manager-loop wait-state and dispatch validation fixes from the
  authorized source snapshot
- adds the RMCP client test dependency required by the process-group cleanup
  regression tests
- keeps Content Pack v9 independently versioned under `content-pack-v9`
- keeps the public distribution boundary at `ontograph/ontocode-cli`

The release is an internal development prerelease. See the
[GitHub release](https://github.com/ontograph/ontocode-cli/releases/tag/rust-v0.4.2.12)
for downloadable assets and checksums.
