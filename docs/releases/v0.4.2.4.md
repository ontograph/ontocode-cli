# Ontocode CLI 0.4.2.4

This internal development prerelease packages the August 19, 2026 development
checkpoint. Its Cargo package version is `0.4.2+4`; the CLI and other
machine-readable version surfaces report `0.4.2+4`, while the GitHub tag,
installer input, and release assets use `0.4.2.4`.

## Included Assets

- Linux x86_64 unsigned `ontocode` binary
- `SHA256SUMS`
- `install-ontocode-linux-x64.sh`
- `install-ontocode-linux-x64-v0.4.2.4.sh`
- `PROJECT_PLAN_AUTHORING_TEMPLATE.md`
- `release-notes-v0.4.2.4.md`
- curated `ontocode-content-pack-0.4.2.4.tar.gz`
- `ontocode-content-pack-0.4.2.4.manifest.json`
- `install-content-pack.sh`

## Scope

- includes current manager-loop recovery and role-routing fixes
- includes session diagnostics publication, Excel offline tooling, and
  workspace skill activation updates from the development checkpoint
- preserves every existing release tag and asset
- publishes repository-owned build and release-publication skills as an
  optional, non-overwriting home or trusted project content pack
- publishes only scrubbed consumer artifacts and release documentation

## Verification

The release gate requires the binary to report `Ontocode CLI 0.4.2+4`, all
staged assets to pass checksum and private-reference scans, and the published
installer to pass an anonymous live-install smoke test.
