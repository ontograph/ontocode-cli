# Ontocode CLI 1.1.4

## Fixed

- Compatible Responses requests now accept batches containing both function
  calls and custom-tool calls, including reversed output arrival order.
- Function and custom calls retain separate identities even when their textual
  call IDs match. Tool payloads are preserved and outputs follow call order.
- An unsupported-tool result no longer causes an otherwise complete mixed
  exchange to fail with an ambiguous-history error.

Missing or duplicate outputs, crossed user/developer message boundaries and
ambiguous internal markers remain rejected. Saved session history is unchanged.

## Validation

- 47 focused client tests passed with retries disabled.
- Library check, Clippy, formatting and scoped source verification passed.

## Distribution

This release provides an unsigned Linux x86_64 binary, installers, the project
plan template and SHA256 checksums. Compatible Responses endpoints must support
structured custom-tool history. The optional content pack is unchanged.
