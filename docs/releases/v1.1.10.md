# Ontocode CLI 1.1.10

Ontocode CLI 1.1.10 ships an unsigned Linux x86_64 binary.

## Removed

- LineageRAG, Knowledge Modules (KM), procedural projection and the
  `ontocode ontograph km` command are removed, along with the `km_context` tool
  and the retired `ontograph-km-librarian` skill. The `/ontograph` TUI command
  (rebuild, tool list, parity), generic hooks and your own KM data on disk are
  kept.
- The `[ontograph]` config table and the `agent_authored_project_knowledge`,
  `lineage_routing` and `lineage_shadow` feature flags are retired. Existing
  configs and config lockfiles that still contain them load and replay without
  error; strict config mode names the retired fields.

## Fixed

- Config lockfiles written before this release no longer fail replay validation
  because of retired feature keys.
- Native Anthropic, Copilot and Gemini adapters accept namespaced tool-call
  history instead of rejecting it.
- Session issue diagnostics no longer report a current Ontograph graph tool
  failure as the removed KM area.
- Starting a review in a non-Git directory is covered by tests that run under a
  read-only profile.

## Performance

- The turn diff summary is cached by content revision, executor stdout and
  stderr are read in a single pass, the models cache renews at half its TTL, and
  config merging, call-output repair, diff summaries and thread lookup avoid
  needless copies and scans.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 1.1.10
```

The binary reports `ontocode 1.1.10`. Release assets include the binary,
installers, project-plan template, and SHA-256 checksums. Agents and skills
continue to ship separately as a content pack.
