# Ontocode CLI 0.4.2.15

Development prerelease for Linux x86_64. The CLI reports `0.4.2+15`.

- Workspace validation capture accepts an optional bounded per-file byte limit,
  allowing declared source files larger than the default 64 KiB to be verified.
- Omitted limits preserve existing defaults and task identity. Invalid,
  duplicate and oversized declarations fail closed; aggregate limits still apply.
- Includes parser, compatibility and capture-boundary regression coverage.

Content Pack v9 remains independently versioned. This release does not include
unfinished recovery or routing changes.

Install:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 0.4.2.15
```
