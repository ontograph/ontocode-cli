# Ontocode CLI 1.1.11

Ontocode CLI 1.1.11 ships an unsigned Linux x86_64 binary.

## Removed

- The librarian chain is removed. It governed Knowledge Module package curation
  and has had no consumer since 1.1.10 removed Knowledge Modules. Sub-agent
  artifact receipts, evidence requirements, the `artifact_receipt_id` and
  `evidence_requirements` spawn arguments, the `artifact_receipts` wait output
  and the `km-curation` task routing are gone.
- The retired role names `librarian`, `librarian-manager`, `librarian-worker`
  and `librarian-reviewer` are rejected through the generic unknown-role path.
- Project-plan templates and the bundled `delegate-to-luna` and
  `ontocode-memory-bank` skill samples no longer mention the librarian gates.

## Compatibility

- State databases written by earlier versions still open. The
  `librarian_artifact_receipts` table and the extra `thread_spawn_edges`
  columns remain in old databases and are ignored.
- No other behavior changes. Coder-role validation, receipts and manager-loop
  dispatch are unchanged.

Install with:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 1.1.11
```

The binary reports `ontocode 1.1.11`. Release assets include the binary,
installers, project-plan template, and SHA-256 checksums. Agents and skills
continue to ship separately as a content pack (v10 already omits the librarian
agents).
