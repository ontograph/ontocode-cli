# Ontocode CLI 0.4.2.14

Development prerelease for Linux x86_64. The CLI reports `0.4.2+14`.

- Rust symbol evidence covers the enclosing item, with an 80-line limit and request-local parse caching.
- Knowledge Module extraction preserves valid facts from mixed drafts. Invalid mappings retain deterministic fallback behavior.
- Includes skill-search regression coverage and lint fixes.

Validation before packaging included 85 Knowledge Module tests and clean library/test lint checks. The release binary is built from committed source and checked for bundled skills. Content Pack v9 remains independently versioned.

Install:

```sh
curl -fsSL https://raw.githubusercontent.com/ontograph/ontocode-cli/main/scripts/install/install.sh | sh -s -- --release 0.4.2.14
```
